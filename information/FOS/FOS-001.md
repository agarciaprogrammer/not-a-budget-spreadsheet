# FOS-001: Flujo Mensual de Asignación Patrimonial
> Versión: 1.0
> Estado: Borrador

---

# 1. Objetivo
Generar una propuesta de asignación patrimonial para el período actual utilizando la información financiera disponible y los datos ingresados por el usuario.

# 2. Actor
* Usuario

# 3. Precondiciones
* El usuario se encuentra autenticado.
* Existe un período mensual disponible para realizar una asignación patrimonial.

# 4. Secuencia Normal
1. El usuario accede al módulo **Asignación Patrimonial**.
2. El sistema presenta el formulario inicial.
3. El usuario informa el ingreso recibido correspondiente al período actual.
4. El sistema valida el ingreso informado.
5. El sistema obtiene automáticamente toda la información histórica necesaria para realizar el cálculo.
6. El sistema presenta los datos obtenidos para su revisión.
7. El usuario revisa la información y confirma que es correcta.
8. El sistema calcula una propuesta de asignación patrimonial.
9. El sistema presenta el resultado al usuario.

# 5. Flujo Alternativo
### 7.1 Información incorrecta
Si el usuario detecta información incorrecta o incompleta, puede modificar los valores antes de confirmar el cálculo.
Una vez corregidos, el flujo continúa desde el paso 8.

# 6. Excepciones
### 4.1 Ingreso inválido
Si el ingreso informado no supera las validaciones del sistema, el usuario deberá corregir el valor antes de continuar.
### 5.1 Información insuficiente
Si el sistema no dispone de la información mínima necesaria para realizar el cálculo, solicitará al usuario completar los datos faltantes antes de continuar.

# 7. Postcondiciones
* Se genera una propuesta de asignación patrimonial para el período actual.
* La propuesta queda disponible para su revisión y posterior ejecución por parte del usuario.
